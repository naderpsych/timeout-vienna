# וינה — המלצות אוכל מ-TimeOut

אתר אישי שאוסף את המלצות האוכל והשתייה של [TimeOut Vienna](https://www.timeout.com/vienna)
ומציג כל מקום ככרטיס נפרד, עם קישור חזרה לכתבה המקורית.

**האתר:** https://naderpsych.github.io/timeout-vienna/

## איך זה עובד

- `scraper.py` — מגלה את מדריכי האוכל באתר ומפרק כל מדריך למקומות
- `enrich.py` — משלים כתובת, שעות פתיחה, תמונה וקואורדינטות
  (Google Maps דרך דפדפן + OpenStreetMap Nominatim — בלי מפתח ובלי הרשמה)
- `docs/` — האתר עצמו (GitHub Pages)

## אוטומציה

| Workflow | מתי | מה |
|---|---|---|
| סריקת וינה | כל יום ב-04:00 UTC | סורק, משלים ומעדכן |
| שומר סף | כל יום ב-09:00 UTC | בודק שהאתר מתעדכן, מריץ סריקת גיבוי ומתריע |
